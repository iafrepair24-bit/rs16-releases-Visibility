Cara pakai

WiFi: di alat buka menu APPLICATION → WI-FI lalu tekan OK sampai ON. Sambungkan HP ke WiFi RS16_0016 (password RS160016).
• Aplikasi APK RS16: buka aplikasi, tekan tombol WiFi di atas.
• Tanpa APK: buka http://192.168.4.1 di Chrome, aplikasi terbuka dari alat dan tersambung otomatis.
Kalau Android bilang "tidak ada internet", pilih tetap tersambung.
Bluetooth: butuh firmware dengan modul BLE (belum aktif di V36.9).
Simulasi: data buatan untuk mencoba aplikasi tanpa alat.

RS16 Race Speed

Mode

Speed: 0-kecepatan, 0-jarak, 0-speed-0, 0-1/4 mile (60 ft, 1/8, trap speed).
Track: lap timer GPS dengan garis finish & sektor, delta live terhadap best lap, prediksi, peta, grafik kecepatan, delta, G-force.

Format data alat

RS,t_ms,lat,lon,kmh,heading,sat,gLat,gLong
Contoh: RS,123456,-6.5351234,106.8561234,123.4,271.3,14,0.85,-0.32

File log CSV dengan format yang sama dari microSD bisa dibuka lewat Riwayat → Import.
