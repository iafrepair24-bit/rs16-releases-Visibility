APLIKASI "RS16 Race Speed" -> tampilan v1.1.3

v1.1.3 (baru):
- Tombol ALAT di layar Riwayat: mengambil riwayat DRAG/SPEED yang tersimpan di alat RS16
  (titik waktu 60 ft / 1/8 / 1/4 / 0-100 dst, top speed, trap, grafik kecepatan).
- Run yang sudah pernah diambil tidak diambil dua kali.
- Butuh firmware alat RS16 V36.9.4 atau lebih baru.
- Riwayat CIRCUIT di alat tidak bisa diambil: alat hanya menyimpan waktu lap, tidak menyimpan jalur GPS.

v1.1.2:
- Di APK, halaman dibuka dari http://app.rs16/ dan kode lama menganggapnya "dibuka dari alat",
  sehingga alamat alat jadi app.rs16 (seharusnya 192.168.4.1). Akibat: koneksi "putus" dan
  "Pasang ke alat" gagal: Unable to resolve host "app.rs16". Sudah diperbaiki.

Cara pasang (Android Studio):
1. Buka proyek RS16RaceSpeed.
2. Ganti file  app/src/main/assets/index.html        dengan index.html di folder ini.
3. Ganti file  app/src/main/assets/web_version.txt    dengan web_version.txt di folder ini (1.1.3).
4. (Disarankan) app/build.gradle: versionCode 4, versionName "1.1.3";
   Config.java: APP_VERSION = "1.1.3".
5. Build -> Build APK, pasang ke HP (timpa aplikasi lama).

Tanpa Android Studio: buka http://192.168.4.1 di Chrome HP (tersambung WiFi RS16).
Tampilan v1.1.3 sudah ikut di dalam firmware V36.9.4, tombol ALAT juga ada di sana.

Cara pakai tombol ALAT:
1. Di alat: menu APPLICATION -> nyalakan WiFi.
2. HP: sambungkan ke WiFi RS16.
3. Aplikasi -> Riwayat -> ALAT -> Ambil.
